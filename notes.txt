The user will provide an RSS feed URL to the application.
The application will provide two ways to interact with the RSS feed.

List Mode:
First, if no other arguments are provided, will list the episodes available in the podcast.
These will be organised as: Episode Number, Release Date, Title

Download Mode:
Second, if they provide a comma seperated list of episodes, will download the requested episodes to the local folder. If the user provides '-' then all episodes will be downloaded.

Design
---
The application download the RSS file locally so that subsequent processing can be simplified.
Because we are working with Docker, we need to pre-create the file names on the local file system.
This means we need to have a processing script that is capable.

The simplest idea I have is to operate with a fixed naming convention.
For example "download".
If we download the podcast to this file name, and then move it afterwards, then that allows us a way of pre-creating the file with the user's permissions.




/usr/local/bin/podcast-dl --url "https://example.com/rss" --episode-template "{{release_date}}_{{title | replace(' ', '_')}}"
